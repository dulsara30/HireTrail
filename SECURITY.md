# Security Policy

## Supported Versions

Only the current main branch and latest deployed releases receive security updates.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in HireTrail, please report it privately. Do not create a public issue.

Please send an email with the vulnerability details, steps to reproduce, and impact assessment to:
`security@hiretrail.local` (or the project owner).

### Response Process

1. Acknowledgement of report within 48 hours.
2. Triage and confirmation of the report with severity assessment.
3. Patch development and internal verification.
4. Deployment of fix to production and notification back to reporter.
