# 09: Build Roadmap and Antigravity Prompts

Give Antigravity one phase at a time, in this order. Start a **new Antigravity conversation for each phase** so its context stays clean. Each phase must end with green lint, type-check, tests and build, and with you reviewing the changes and committing them yourself.

The agent builds everything from scratch, following `AGENTS.md`. It never commits, pushes or adds itself as an author. You commit.

Rough effort for evenings and weekends: phases 0–3 are the core (about 3–4 weeks). Later phases are about a week each.

## How every phase works

1. Open a new Antigravity conversation in the repo.
2. Paste the phase prompt below.
3. Antigravity replies with a plan (files, tests, open questions). Read it. Ask for changes or say "approved".
4. It implements. When it says it's done, ask it to run `pnpm lint && pnpm typecheck && pnpm test && pnpm build` and show the output.
5. Try the feature yourself locally.
6. Review the diff (`git diff`, or the source-control panel). Ask for fixes if needed.
7. Commit yourself, using the commit message it proposes (no co-author lines), push the branch, open a PR, let CI pass, merge.
